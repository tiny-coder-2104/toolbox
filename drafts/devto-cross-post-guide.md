# Dev.to Cross-Posting Guide

## Setup
1. Create Dev.to account (if not exists)
2. Connect GitHub account for import

## Import Process
For each article:
1. Go to https://dev.to/new
2. Click "Import from URL"
3. Enter canonical URL: `https://toolbox-lilac-three.vercel.app/blog/ARTICLE.html`
4. Dev.to will pull content automatically
5. Verify canonical URL is set correctly in the import

## Article Order (1/day)
1. **Day 3:** Vanilla JavaScript PWA Tutorial (highest search volume)
2. **Day 4:** How to Make Any Web App Installable on Android
3. **Day 5:** PWA vs Native App
4. **Day 6:** JSON Formatter Online

## Cross-Posting Checklist
- [ ] Canonical URL points to original blog
- [ ] Title matches original
- [ ] All code snippets preserved
- [ ] Links to TinyCoder tools work
- [ ] Gumroad CTA present
- [ ] UTM parameters preserved

## Publishing Schedule
- Post at 9am ET (highest engagement)
- Share on Twitter/X immediately after
- Reply to all comments within 30 minutes

## Dev.to Community Rules
- No duplicate posts (canonical URL handles this)
- No excessive self-promotion (10:1 ratio)
- Engage with other posts before posting your own
- Reply to comments on your posts
