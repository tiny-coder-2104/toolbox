# Project: TinyCoder Web Toolbox

## Overview
A clean, ad-free, privacy-first collection of essential developer tools running entirely in the browser. No backend, no data leaves the client.

## Product
Developer Utility PWA — browser-based versions of common CLI/networking/security tools.

## MVP Tools
1. JSON formatter / validator / minifier
2. Base64 encoder/decoder
3. Regex tester (with flags, match highlights)
4. URL encoder/decoder
5. UUID generator

## Key Constraints
- Zero budget — all free tools only
- Client-side only — no backend code
- Must ship fast — first sell within 5-7 days
- Ubuntu 18.04 base machine

## Current Phase
Planning → Setup → Build MVP → Deploy → Sell

## Hosting
Netlify (free tier, auto-HTTPS, Git-based deploys)

## Payments
Gumroad or LemonSqueezy (free to list, handle payments and delivery)

## Target Audience
Developers, sysadmins, security professionals — people who already search for these tools online
